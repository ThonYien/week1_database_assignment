# Student Management Database

## Project Description
This project demonstrates how to create and manage a MySQL database using MySQL Workbench. The database is called `school`, and it contains a table named `students` for storing student information.
## Table Structure
The `students` table contains the following columns:

- `id` – Student's unique identification number.
- `name` – Student's full name.
- `email` – Student's email address.
- `age` – Student's age.
- `course` – Student's course.
## SQL Operations
The following SQL operations were performed:
1. Created the `school` database.
2. Selected the database using `USE school`.
3. Created the `students` table.
4. Inserted four student records.
5. Displayed records using `SELECT`.
6. Updated student information.
7. Deleted a student record.
8. Viewed the table structure using `DESCRIBE`.
